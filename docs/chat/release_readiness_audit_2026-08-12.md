# JPBA新サイト 総点検結果（2026-08-12）

## 結論

- 管理ホームの移動ボタンは、用途別の色付きボタン・カード上辺・矢印へ変更済み。
- 主要管理23画面中22画面、主要公開15画面中15画面はHTTP 200。
- DBの主要データ整合性と権限分離は良好。
- ただし、旧公式サイト閉鎖前および本番公開前に対応すべき重要項目が残っているため、現時点の判定は「条件付き・本番公開前修正あり」。

## 最優先（旧公式サイト閉鎖前）

### 1. 選手写真を新サイト内へ保存する

- 公開対象2,286選手のうち2,262選手に写真パスがある。
- 2,262件すべてが `/assets/img/prof/...` の旧パスを参照し、新サイト内の実ファイルは0件。
- 川添奨太プロの公開プロフィールでも画像欠落を実ブラウザで確認した。
- 旧サイトへの一時フォールバックでは閉鎖後に再度壊れるため、写真を新サイト側へ保存し、DBパスを新しい保存先へ更新する必要がある。

### 2. 公開ページの旧サイト依存を移行する

- `config/jpba_public.php` に `jpba1.jp` へのリンク28件、`jpba.or.jp` へのリンク6件が残る。
- 協会資料、インストラクター、プロテスト、問い合わせ、メディア、遵守事項などが旧ページ・旧PDFへ依存している。
- 閉鎖対象を確認し、必要なPDF・内容を新サイト内へ保存して内部リンクへ置き換える。

## 高優先（公開前）

### 3. 大会運用ログ画面を修正する

- `/tournaments/124/operation-logs` はHTTP 500。

- 同画面には未定義の操作ルートが2件ある。
  - `tournaments.results.apply_awards_points`
  - `tournaments.results.sync`

  - 使用ボール期限切れ削除
  - 検量証未登録データの年末処理
  - 講習通知
  - 大会抽選リマインダー
  - 未処理大会の自動抽選
- `routes/console.php` またはLaravel 12のスケジュール設定へ移し、`schedule:list` と実行ログで確認する。
