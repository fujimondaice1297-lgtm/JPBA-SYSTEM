# 年度ボール申請・承認 操作手順（2026-08-10）

## 選手本人

1. 選手マイページの「年度ボール申請」を開く。
2. 対象年度と自分の氏名を確認する。
3. その年度に使用する現物ボールへチェックを付ける。
4. 途中なら「下書き保存」、確定したら「スタッフ承認へ提出」を押す。
5. 状態が「承認待ち」になった後は、スタッフの承認または差戻しまで内容を変更できない。
6. 「承認済み」になったボールは、同年度の大会使用ボール画面で選択できる。

## スタッフ

1. 上部ナビまたは左メニューの「年度ボール申請・承認」を開く。
2. 年度を指定し、氏名・カナ・ライセンス番号で選手を検索する。
3. 「内容確認・代理申請」で選択内容を確認する。必要なら代理で下書き・提出する。
4. 承認待ちの選手は「一括承認」で、その申請版に含まれる全ボールをまとめて承認する。
5. 修正が必要な場合は理由を入力して「差戻し」を押す。

## 年度途中に追加する場合

- 承認済み内容を元にチェックを追加・入れ替えして再提出する。
- 新しい申請は次の版として保存される。
- 新版が承認されるまでは直前の承認版が有効なため、既存の大会登録は止まらない。
- 新版の承認後は、その版に含まれるボールが同年度の正しい承認内容となる。

## 大会使用ボール画面

- 大会開催年の最新承認版に含まれるボールだけ、新しく大会へ追加できる。
- 年度承認前から既に大会へ登録されていたボールは履歴保護のため表示を残すが、一度外すと承認なしでは再追加できない。
- 年度承認と検量証は別条件。検量証の有効期限は検量日から1年間で、年度をまたげる。
