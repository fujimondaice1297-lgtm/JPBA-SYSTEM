# 大会エントリー・使用ボール登録 実地確認手順

更新日: 2026-07-31

## A. スタッフ代理入力で確認する方法（推奨）

選手アカウントを作る前でも、大会・選手・ボールの接続を一通り確認できる。

1. 管理者または編集者でログインする。
2. 上部メニューの「大会管理」から「大会一覧」を開く。
3. 確認に使う既存大会カードの「選手・ボール登録」を押す。
4. 「参加選手を直接登録」に対象選手のライセンスNoを入力し、「参加選手を登録」を押す。
5. 参加一覧に追加された選手の「0個 / 登録・閲覧」を押す。
6. ボールが未登録なら「本登録を追加」を押す。
7. ライセンスNoが対象選手であることを確認し、メーカー・発売年で絞り込み、ボール、シリアルナンバー、登録日を入力する。
8. 検量証番号は空欄でも保存できる。空欄は仮登録、入力時は登録日から1年−1日を有効期限とする。
9. 保存後に大会使用ボール画面へ戻るので、使用するボールへチェックを付けて「選択内容を保存」を押す。
10. 「大会の選手一覧へ戻る」を押し、ボール数が1個以上になったことを確認する。
11. 再度「登録・閲覧」を押すと、大会・選手・ボール名・シリアルNo・検量証状態を確認できる。

### 大会全体の登録状況確認

1. 大会一覧から対象大会の「選手・ボール登録」を開く。
2. 上部カードで「ボール登録あり」「ボール未登録」「検量証要確認」「期限間近あり」「上限超過」の人数を確認する。
3. カードをクリックすると、その状態の参加選手だけに絞り込まれる。
4. 検索欄の「ボール登録状況」からも、要確認のみ・未登録・登録ありなどを選択できる。
5. 各選手の「現在数 / 大会上限 / 登録・閲覧」を押すと、その選手の代理入力画面へ進む。
6. ウェイティング選手は「参加確定後に登録」と表示し、ボール登録状況の集計対象外とする。

登録ボールのチェックを外して保存すると大会から解除できる。上限到達時も、既存のチェックを外して別のボールへチェックを付ければ入れ替えできる。

## B. 選手本人ログインで確認する方法

### 事前条件

- 対象選手のプロフィールに本人メールアドレスが登録されていること。
- 対象選手に紐づく会員アカウントがあること。ない場合はログイン画面の「新規登録」で、プロフィールと一致するライセンスNo・メールアドレスを使って作成する。
- 対象大会の編集画面で、申込開始日時と申込締切日時が現在日時を含んでいること。
- 対象選手が競技者・会員有効・公式戦出場可であること。

### 操作

1. 選手本人のアカウントでログインする。
2. マイページの「大会エントリー・使用ボール登録」を押す。
3. 対象大会を「エントリーする」にして「保存する」を押す。
4. 対象大会の「大会使用ボール登録」を押す。
5. ボールが未登録なら「本登録を追加」から、ボール・シリアルナンバー・登録日・必要に応じて検量証番号を登録する。
6. 大会で使用するボールにチェックを付け、「選択内容を保存」を押す。
7. 大会エントリー一覧に戻り、「ボール登録済み」と表示されることを確認する。
8. スタッフでログインし、大会カードの「選手・ボール登録」から対象選手の「登録・閲覧」を押して、同じ内容が見えることを確認する。

## 警告確認

- USBC掲載確認済みのボールは警告なし。
- `NANODESU 9 BLUE` は「アブプールリストに記載のないボールです」と赤字警告するが、登録自体は可能。
- 検量証番号が空欄の場合は「仮登録 / 検量証待ち」と表示する。
- 検量証必須の大会では、検量証未登録または大会開催日時点で期限切れのボールを「大会使用不可」と表示し、新規選択と保存を禁止する。
- 検量証の有効性は検量証番号と有効期限で判定する。開発途中の過去データを考慮し、検量日より前の大会かどうかは判定しない。
- 期限間近は有効期限30日前から表示する。再検量時は実際の検量日を入力すると、有効期限が1年−1日後へ自動更新される。
- 使用ボール側で検量証を更新した場合、同じ選手・シリアルの本登録ボールにも同時反映する。

## 現在のローカルデータに関する注意

- 2026-07-31時点でログインアカウントは管理者1件のみで、選手に紐づく会員アカウントは0件。
- 直近の既存大会は申込開始日時・申込締切日時が空欄のため、選手本人の大会エントリー一覧には表示されない。
- まずはAのスタッフ代理入力で確認し、その後に選手本人テスト用アカウントと申込期間を設定してBを確認する。
