# 公開選手プロフィール・褒章管理UI

実施日: 2026-07-29

## 実装内容

- 一般公開の選手プロフィールで、タイトル欄の直後に「褒章」欄を追加。
- 公認パーフェクト、公認800シリーズ、公認7－10メイドを種別ごとに表示。
- 明細はタイトル履歴と揃えて「年 / 大会名 / 達成ゲーム等（年月日）」形式で表示。
- 公開画面には公式資料URLを表示しない。
- 明細未確認分は「その他過去達成数」と注記を表示。
- 選手編集画面の褒章明細に「編集」「削除」を追加。
- 編集・削除後は選手編集画面へ戻る。
- 確認済み明細を削除しても、正となるプロフィール総数は減らさない。
