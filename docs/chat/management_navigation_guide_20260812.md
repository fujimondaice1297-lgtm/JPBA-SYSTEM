# 管理者画面・作業導線ガイド（2026-08-12）

## 入口

- 管理者・編集者でログインすると、上部メニューの「管理ホーム」から管理者ワークスペースを開ける。
- URLは `/management`。
- 従来の管理者専用URL `/admin` も同じ管理トップを表示する。

## 管理ホームの構成

1. **よく使う操作**
   - 大会選択、速報入力、選手検索、年度ボール承認、お知らせ作成へ直接移動する。
2. **対応状況**
   - 30日以内の大会、準備中大会、年度ボール承認待ち、今年度大会の件数を表示する。
3. **大会運営の流れ**
   - 「大会準備 → 参加受付 → 大会当日 → 確定・公開」の順に画面を選べる。
4. **大会ごとの作業**
   - 直近の大会から、設定・参加者・速報・成績・公開へ直接移動する。
5. **すべての作業メニュー**
   - 全機能を作業内容別の6分類から選ぶ。

## 作業分類

- 大会準備
- 参加受付・ボール
- 大会当日
- 大会終了後
- 選手・資格
- 広報・システム

上部メニュー、左メニュー、管理ホームは同じ分類と名称を使用する。

## 権限

- 管理者：全項目を表示する。
- 編集者：削除・通知・INFORMATION管理など、管理者専用項目は表示しない。
- 選手：従来どおり選手マイページ、エントリー、マイボール、年度ボール申請を表示する。

## 運用上の注意

- 既存画面のURLは変更していないため、従来のブックマークも利用できる。
- 大会ごとの参加者・速報・成績・公開は、管理ホームの大会行から直接開く。
- 新しい管理機能を追加するときは `App\Support\ManagementNavigation` の該当分類に入口を追加し、上部・左・管理ホームの分類をそろえる。
