# 2026-08-14 選手会員種別の年度自動判定

## 正式な判定順

1. 非アクティブ会員は `死亡` / `除名` / `退会届` を維持する。
2. プロ・認定インストラクターは各インストラクター区分を維持する。
3. 当年度の男子トーナメントシードは `第１シード` とする。
4. 当年度の女子トーナメントシード1～18位は `第１シード`、19～36位は `第２シード` とする。
5. TP講習が有効で、当年度公式大会の `tournament_results` に出場履歴がある選手は `トーナメントプロ` とする。
6. TP講習が有効で、当年度公式戦出場履歴がない選手は `講習会出席者` とする。
7. 上記以外でK/P海外ライセンス、英字・ハングル・全角カタカナ名の選手は `海外プロ` とする。
8. 上記のどこにも該当しない選手は `その他` とする。

氏名の海外判定には公開氏名 `name_kanji` だけを使う。全選手の `name_kana` はカタカナのため判定材料にしない。海外プロとその他は内部区分も分離し、`海外プロ=honorary_or_overseas`、`その他=other` とした。
地区マスタの「海外」は名誉プロやテストデータにも使われているため、海外プロ判定には使わない。

## 年度更新

- `php artisan pro-bowlers:sync-membership-types --year=2026 --dry-run` で変更せずに確認できる。
- `php artisan pro-bowlers:sync-membership-types --year=2026` で対象年度を反映する。
- 毎日02:30に現在年度を自動再判定するため、年度替わり、シード更新、公式成績追加、講習履歴更新が翌日までに反映される。
- 個別受講登録、講習一括登録、選手編集では保存直後にも対象選手を再判定する。
