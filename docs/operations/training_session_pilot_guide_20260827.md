## 自動ロールバック監査

本番データを作らず、開催回作成から資格反映までを一時データで確認する。

```powershell
php artisan jpba:audit-training-workflow
php artisan jpba:audit-training-workflow --smoke
```

`--smoke` は次を順番に実行し、最後に全件ロールバックする。

1. 非公開の一時選手2名と講習会開催回を作成する。
2. 受講済み1名、未受講1名を登録する。
3. 結果を確定し、受講済み選手の3年期限と大会出場資格を確認する。
4. 受講者CSVと期限通知候補を確認する。メールは送信しない。
5. 確定を解除し、受講済みを未受講へ訂正する。
6. 旧受講履歴が無効化され、大会出場資格なしへ戻ることを確認する。
7. 一時データをロールバックし、主要6表の件数が試験前と同じことを確認する。

## 実際の開催回を登録する手順

1. 管理ホームの「選手・資格」から「TP講習会」を開く。
2. 年度を選び、「＋ 講習会を作成」から名称、開催日、会場、備考を登録する。
3. 本人確認済みの受講対象者ライセンス番号を貼り付ける。
4. 当日は全員を「受講済み」「未受講」「免除」のいずれかへ変更する。「受講予定」を残さない。
5. 「結果を確定・資格へ反映」を押す。
6. 受講者CSVを保存し、受講済み人数、未受講人数、有効期限を照合する。
7. 誤りがあれば「確定を解除」し、修正後にもう一度確定する。
8. 選手編集と大会エントリー画面で、開催日時点の出場資格を確認する。

## 期限通知

送信前は必ずdry-runで人数だけを確認する。

```powershell
php artisan training:notify --expiry-year=2027 --dry-run
```

本番メール設定、対象年度、対象人数、文面が承認されるまで、`--dry-run` を外さない。定期処理は毎日08:00に同じ候補を確認し、送信済み履歴で重複を防止する。
