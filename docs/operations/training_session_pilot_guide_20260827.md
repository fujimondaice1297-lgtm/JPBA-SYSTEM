
6. 確定を解除し、受講済みを未受講へ訂正する。

## 公式修了者一覧と開催回の扱い

- 第25回は会場で同日に開催する方式ではなく、各選手がオンライン動画を視聴し、テスト回答を提出する方式である。
- 公式PDFは更新時点までの累積修了者一覧で、個々の正確な受講日を掲載していない。
- 公式PDFの公開日を643名共通の受講日として登録しない。公開一覧は従来どおり公式サイクル単位の資格根拠として保持する。
- 新システムで今後受け付ける個別修了分は、事務局が確認した実際の受講日を開催回へ登録する。

## 実際の開催回を登録する手順

1. 管理ホームの「選手・資格」から「TP講習会」を開く。
2. 年度を選び、「＋ 講習会を作成」から名称、開催日、会場、備考を登録する。
3. 本人確認済みの受講対象者ライセンス番号を貼り付ける。
4. 当日は全員を「受講済み」「未受講」「免除」のいずれかへ変更する。「受講予定」を残さない。
5. 「結果を確定・資格へ反映」を押す。
6. 受講者CSVを保存し、受講済み人数、未受講人数、有効期限を照合する。
7. 誤りがあれば「確定を解除」し、修正後にもう一度確定する。
8. 選手編集と大会エントリー画面で、開催日時点の出場資格を確認する。

## 期限通知

送信前は必ずdry-runで人数だけを確認する。

```powershell
php artisan training:notify --expiry-year=2027 --dry-run
```

本番メール設定、対象年度、対象人数、文面が承認されるまで、`--dry-run` を外さない。定期処理は毎日08:00に同じ候補を確認し、送信済み履歴で重複を防止する。
