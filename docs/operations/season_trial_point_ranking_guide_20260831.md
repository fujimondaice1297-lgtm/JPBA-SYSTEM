# シーズントライアルポイント・優先出場一覧 運用手順

更新日: 2026-08-31

## 1. 基本方針

- シーズントライアルで付与されたポイントは、同じ値を次の2系統へ加算する。
  - 公式ポイントランキング
  - シーズントライアル年間ポイントランキング
- 大会設定は `counts_for_official_points = true` とし、成績出力には次の両方を持たせる。
  - `points / official`
  - `points / season_trial_championship`
- ランキング画面は保存済みの別表を手入力更新せず、各大会の「現在版」の確定成績から表示時に再集計する。
- 成績を訂正して再公開した場合は、旧版を含めず現在版だけを集計する。

## 2. 画面への導線

管理ホームの「大会終了後」または上部メニュー「成績・速報」から次を開く。

1. `公式ポイントランキング`
2. `ST年間ポイントランキング`
3. `STチャンピオンズ優先出場`

直接URL:

- `/rankings/season-trial`
- `/rankings/season-trial/championship-priority`

正会員、編集者、管理者が閲覧できる。公式ランキングの取込・確定操作は従来どおり編集者・管理者だけが行える。

## 3. 大会終了後の更新手順

1. 大会成績を入力し、ポイント内訳を確認する。
2. 成績公開画面で現在版として確定・公開する。
3. `ST年間ポイントランキング` を開き、会場数と選手ポイントを確認する。
4. `STチャンピオンズ優先出場` を開き、選考区分とランキング枠を確認する。

ランキング用の追加登録や再計算ボタンは不要。公開または再公開された時点で次回表示へ反映される。

## 4. ST年間ランキング

- ウィンター、スプリング、サマー、オータムを分けて表示し、年間合計を併記する。
- 同ポイントの場合は、当該年度のシーズントライアルで投球したトータルピンが多い選手を上位とする。
- 表示項目は順位、選手、各シリーズポイント、年間ポイント、トータルピン、ゲーム数、アベレージ。
- アベレージは合計トータルピン ÷ 合計ゲーム数で再計算する。

## 5. STチャンピオンズ優先出場

選考順は次のとおり。先の区分で選ばれた選手は後の区分へ重複表示しない。

1. 当該年度トーナメントシードプロ
2. 当該年度公認トーナメント優勝者シードプロ
3. 永久シードプロ
4. 当該年度シーズントライアル各会場優勝者
5. スポンサー推薦
6. 上記以外のST年間ポイントランキング上位者

定員は55名。①～⑤を先に選び、残りを⑥のランキング順で埋める。大会途中の一覧は暫定であり、成績公開、公式タイトル確定、推薦登録に応じて自動で入れ替わる。

スポンサー推薦は、対象年度の大会名に `STチャンピオンズ` を含む大会へ「本大会スポンサー推薦」として登録した選手を参照する。

## 6. 既存大会の補正

`2026_08_31_000001_enable_official_points_for_season_trials` で、既存のシーズントライアル大会を次の状態へ統一する。

- 公式ポイント対象を有効化
- 公式ポイント出力を追加
- シーズントライアル標準テンプレートの設定を同じ内容へ更新

2026-08-31時点では16大会すべて補正済み。完了済み12会場は成績を変更せず、未開催のオータム4会場は今後の成績公開時から両ランキングへ反映される。

## 7. 確認時の注意

- 大会の入力途中スコアは年間ランキングへ含めない。現在版として確定公開された結果だけが正本。
- 再公開後に会場数が増えた場合は、同じ大会に現在版が二重作成されていないかを確認する。
- 手動でランキング順位を上書きしない。誤りがある場合は大会成績または選手・シード・タイトル・推薦の正本を訂正する。
