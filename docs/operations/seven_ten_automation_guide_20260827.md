# 公認7－10メイド自動候補 運用ガイド（2026-08-27）

## 判定条件

スコアシートが「確定」で、次の条件をすべて満たすフレームだけを確認待ち候補にする。

1. 残りピンが7番・10番の2本だけである。
2. 1～9フレームは第1投が8本、次投球がスペア `/` である。
3. 10フレームは、第1投が8本なら第2投が `/`、第1投がストライクなら第2投が8本で第3投が `/` である。
4. スコアシート選手が `pro_bowlers.id` に紐付いている。

残りピンに他の番号が含まれる、次投球がスペアでない、未確定、選手未結線のいずれかなら候補にしない。推測による自動確定は行わない。

## 入力と確認

1. 大会のスコアシート入力で投球記号を入力する。
2. メイド直前の残りピンとして7番と10番だけを選択する。
3. スコアシートの「確定」を選んで保存する。
4. 公認記録管理の「確認待ち」で大会、選手、ゲーム、フレーム、根拠を確認する。
5. 正しければ確認する。男女・記録種別ごとの次番号が自動採番され、後から編集できる。

候補確認までは公認件数へ加算しない。確認後は新規達成分として一度だけ加算する。

## 訂正

- 確認前に投球、残りピン、確定状態、選手を訂正すると、該当しなくなった候補は自動で無効になる。
- 確認済み記録の根拠を訂正しても、明細や総数を自動削除しない。代わりに警告を付け、スタッフが確認する。
- 条件を元へ戻すと根拠リンクと警告を再同期する。公認件数は二重加算しない。

## 一括再走査

```powershell
php artisan jpba:detect-achievement-candidates --json
```

出力の `seven_ten_candidates_created` は、その走査で新たに作成した確認待ち候補数。既存候補の再確認や訂正同期は新規数に含めない。

## 現行データ確認

2026-08-27時点で、67スコアシート、1,870フレームを含む26大会を走査した。残りピンが7番・10番だけのフレームは1件あったが、次投球が1本のためメイドではなく、新規候補は0件だった。
