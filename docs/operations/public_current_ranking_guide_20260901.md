# 当年度ポイント・賞金ランキング 公開運用手順

更新日: 2026-09-01

## 1. 公開場所

一般サイトの上部メニュー「速報・成績」を開き、「当年度公式ランキング」から次を選ぶ。

- 男子ポイントランキング
- 女子ポイントランキング
- 男子賞金ランキング
- 女子賞金ランキング

直接URLは `/rankings/current`。`year`、`gender=M|F`、`type=points|prize` で表示を切り替える。

## 2. 集計の正本

- 各大会の確定・再公開された「現在版」成績だけを集計する。
- 公式ポイントは、大会設定の `counts_for_official_points` が有効な大会だけを加算する。
- 賞金は、`counts_for_prize` が有効な大会だけを加算する。
- ゲーム数、トータルピン、AVGは、`counts_for_average` が有効な大会だけを加算する。
- 再公開時は旧版を含めない。別途ランキング行を手入力する必要はない。

## 3. 大会終了後の確認

1. 大会成績を現在版として確定・公開する。
2. 一般サイト「速報・成績」から男女のポイントランキングを確認する。
3. 同画面を賞金ランキングへ切り替え、獲得賞金と順位を確認する。
4. 誤りがある場合はランキング表を直接直さず、大会成績または大会の集計対象設定を訂正して再公開する。

## 4. 対象外大会

女子トーナメント出場優先順位決定戦は、出場優先順位を決める選考会であり、公式ポイント、STポイント、賞金、タイトルへ反映しない。大会作成・更新と結果出力の両段階でこの条件を固定する。
