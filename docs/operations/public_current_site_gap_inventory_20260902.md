# 現行サイトと新サイトの一般公開差分（2026-09-02）

## 目的

現行JPBAサイトの閉鎖後も一般利用者が必要情報へ到達できるよう、一般公開ページを比較し、移行済み・今回移行・追加移行が必要な項目を明示する。
旧サイトへリンクして延命せず、本文・資料・画像またはDBデータを新サイト内の正本へ移す。

## 残っている移行項目

次の項目はHTMLを1枚移すだけでは正しく運用できず、年次データ・添付資料・選手や大会との対応付けが必要である。今回の「そのまま移せる固定ページ」には含めず、移行対象として残す。

| 優先 | 未移行または不足している項目 | 現在確認できた状態 | 必要な移行方式 |
|---:|---|---|---|
| 2 | 公認大会・承認イベント一覧 | 専用一般ページなし | 大会分類・主催者・開催情報をDB化 |
| 3 | 公認オイルパターン | 専用資料一覧なし | 大会・年度・会場との関連を持つPDF管理 |
| 3 | プロワッペン案内 | 専用固定ページなし | 本文と画像を公開ページ管理へ移行 |
| 3 | 年度別インストラクター資格講習の資料アーカイブ | 最新案内はINFORMATION運用、過年度資料なし | 年度・資格別PDFをINFORMATIONへ取込 |
| 3 | 協賛バナーの画像管理 | 法人一覧は移行、トップのバナーCMSは未実装 | 画像、URL、公開期間、表示順をDB管理 |

## 次の実装順

1. 公認大会・承認イベント一覧を大会分類と結び付けて公開する。
2. 保存済みオイルパターンを大会・年度・会場から横断検索できるページを追加する。
3. プロワッペン、講習資料の文書アーカイブを整備する。
4. 協賛バナーを管理画面で差し替えられるようにする。
