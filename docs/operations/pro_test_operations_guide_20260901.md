# プロテスト速報・結果 運用手順

## 目的

管理画面で受験者と得点を処理し、確認済みの情報だけを一般サイトへ公開する。途中結果では受験者の年齢、生年月日、詳細住所、電話、メールを扱わない。

## 標準フロー

1. 管理ホームの「選手・資格」から「プロテスト運用」を開く。
2. 年度、名称、実施期間、申込期間、男女の期別を登録する。
3. 男女、第1次・第2次・第3次、日別に実施日と累計ゲーム番号を登録する。
4. 受験者を開始段階・免除理由とともにCSVまたはExcel貼り付けで一括登録する。
5. 各実施日の得点を貼り付けて保存する。
6. 入力件数と集計を確認後、管理者が「速報を確認済みとして公開」を押す。
7. 訂正時は内部得点を修正し、再度公開する。一般ページには第2版、第3版として最新の公開版だけが表示される。
8. 全テスト終了後、全員分の最終結果を内部登録する。
9. 管理者が合格者一覧を公開する。一般ページには不合格者・棄権者を表示しない。
10. 合格者のプロボウラー登録後、ライセンス番号を再登録して選手マスタへ紐付ける。以後のプロフィール項目は選手プロフィールの公開・非公開設定に従う。

## 貼り付け形式

### 受験者

```text
受験番号,性別,氏名,フリガナ,居住都道府県,利き腕,開始段階,免除理由,前年受験番号,承認メモ
M001,男子,日本 太郎,ニホン タロウ,東京都,右,第1次,通常受験,,
M002,男子,再受験 次郎,サイジュケン ジロウ,大阪府,右,第2次,前年第2次不合格,M010,
M003,男子,承認 三郎,ショウニン サブロウ,愛知県,右,第2次,アマチュア好成績,,協会承認日と根拠
M004,男子,特例 四郎,トクレイ シロウ,福岡県,右,第3次,プロ公式戦アマ優勝,,対象大会名
```

開始段階・免除理由を省略した6列形式は、第1次からの通常受験として扱う。

### 免除・開始段階

- 通常受験は第1次から登録する。
- 第2次不合格者は、直後の翌年度に限って第1次を免除し、第2次から登録できる。
- 上記の免除を利用した年度に第2次で再び不合格となった場合、次年度は第1次から登録する。連続して免除を利用することはできない。
- アマチュア時代の好成績を協会が承認した場合は、第1次免除として第2次から登録する。
- プロ公式戦でプロを抑えて優勝したアマチュアは、実技免除として第3次から登録する。
- 免除対象者は管理画面の候補一覧から前年受験番号を確認し、協会承認特例は承認根拠をメモへ残す。
- 開始段階より前の実技得点は入力できない。第3次が面接・講習等で得点を持たない場合は、段階別結果だけを登録する。

### 段階別結果

```text
受験番号,段階,結果,備考
M001,第1次,合格,
M002,第2次,不合格,翌年度第1次免除対象
```

結果は「合格」「不合格」「棄権」「未確定」を使用する。開始段階より前の「免除」は受験者取込時に自動作成する。最終日かつ合格AVG設定済みの速報を公開すると、必要ゲーム数が揃った受験者は自動判定される。

### 得点

実施日に設定したゲーム数まで入力する。空欄は既存値を維持し、誤登録したゲームを未入力へ戻す場合は `-` とする。

```text
M001,200,210,225
```

### 最終結果

```text
受験番号,結果,ライセンス番号
M001,合格,M00001500
M002,不合格,
```

結果は「合格」「不合格」「棄権」「未確定」を使用する。

## 公開境界

- 編集者は年度、日程、受験者、得点、最終結果を入力できる。
- 一般速報と合格者一覧の公開操作は管理者だけが行う。
- 得点を保存しただけでは一般ページは更新されない。
- 公開速報は受験番号、氏名、フリガナ、居住都道府県、利き腕、ゲーム得点、ゲーム数、トータル、AVG、結果だけを保持する。
- 最終結果ページは合格者だけを表示する。
- 合格後の選手プロフィールでは、既存のプロフィール公開・非公開設定を正本とする。

## 2025年現行サイトとの対応

- 年度ページ：新サイトの年度別「速報・結果」ページに対応する。
- 第1次・第2次の日別PDF：新サイトの日別公開版に対応する。
- 最終合格者：新サイトの合格者公開に対応する。
- 合格者プロフィール：`pro_bowlers` への紐付け後、一般選手プロフィールへ接続する。
- 過去PDFの移管は別工程とし、来年度以降のDB正本運用には外部PDFを必要としない。
