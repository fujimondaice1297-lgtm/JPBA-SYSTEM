# ダブルエリミネーション方式 運用設計

更新日: 2026-09-12

## 適用範囲

現時点の実装対象は、ジャパンオープンの男子マスターズ／女子クイーンズ決勝で使用する8名方式である。一般的なダブルエリミネーションへ一律適用せず、`template_snapshot.japan_open.component_code` が `masters` または `queens` の大会だけで動作させる。

根拠はJPBA公式の大会要項、決勝組み合わせ表、正式成績とする。

- 2025決勝組み合わせ表: https://www.jpba.or.jp/information/tournament/tournament2025/15_JO/PDF/DE_MatchTable.pdf
- 2025大会要項: https://www.jpba.or.jp/information/tournament/tournament2025/15_JO/PDF/JO_Guide.pdf
- 2025正式成績: https://www.jpba.or.jp/information/tournament/tournament2025/15_JO/Result/FinalResult.pdf

## 決勝進出者

- 選出元は、予選8G＋準決勝6Gを合算した最新の `semifinal_total` スナップショットに限定する。
- 14G完投者の上位8名を通過順位として保存する。
- 8位と9位が同ピンの場合は自動同期を止め、タイブレーク後の順位反映を求める。
- 1回戦は `1位対8位`、`4位対5位`、`2位対7位`、`3位対6位` とする。

## 対戦構造

通常の各対戦は2G合計、第3位決定戦・優勝決定戦・再優勝決定戦は1Gとする。

| コード | 対戦 | 進出元 |
|---|---|---|
| W1 | 勝者ゾーン1回戦 第1試合 | 1位 / 8位 |
| W2 | 勝者ゾーン1回戦 第2試合 | 4位 / 5位 |
| W3 | 勝者ゾーン1回戦 第3試合 | 2位 / 7位 |
| W4 | 勝者ゾーン1回戦 第4試合 | 3位 / 6位 |
| W5 | 勝者ゾーン2回戦 第1試合 | W1勝者 / W2勝者 |
| W6 | 勝者ゾーン2回戦 第2試合 | W3勝者 / W4勝者 |
| L1 | 敗者復活1回戦 第1試合 | W1敗者 / W2敗者 |
| L2 | 敗者復活1回戦 第2試合 | W3敗者 / W4敗者 |
| L3 | 敗者復活2回戦 第1試合 | L1勝者 / W6敗者 |
| L4 | 敗者復活2回戦 第2試合 | L2勝者 / W5敗者 |
| W7 | 勝者ゾーン3回戦 | W5勝者 / W6勝者 |
| L5 | 敗者復活3回戦 | L3勝者 / L4勝者 |
| TP | 第3位決定戦 | L5勝者 / W7敗者 |
| GF1 | 優勝決定戦 | W7勝者 / TP勝者 |
| GF2 | 再優勝決定戦 | GF1でW7勝者が敗れた場合だけ同じ2名 |

## 勝敗・同点・再優勝決定戦

- 2G戦は2枚の確定スコアシートの合計点で勝敗を決める。
- 2G合計が同点の場合は次の対戦を作らず、タイブレーク後の勝者を管理画面で指定する。
- 1G戦が同点の場合は、既存スコアシートの「タイブレーク後の勝者」を利用する。
- 優勝決定戦で無敗側のW7勝者が勝てば、その時点で優勝者を確定する。
- 敗者側のTP勝者が勝った場合は両者1敗となるため、GF2を自動生成する。GF2勝者を優勝、敗者を準優勝とする。

## 保存先と安全策

- 新規テーブルは作らず、ゲーム別入力は既存の `tournament_match_score_sheets`、選手は `tournament_match_score_sheet_players`、フレームは `tournament_match_score_frames` を使用する。
- 8名の通過順位、同期元スナップショット、同点勝者、最終同期状態は `tournaments.template_snapshot.japan_open.double_elimination` に保存する。
- 対戦者は前の対戦が確定した段階で自動生成し、未確定の将来対戦へ推測で選手を入れない。
- 得点入力済みの対戦者と14G再同期後の選手が食い違う場合は、自動上書きせず停止する。
- 自動生成された対戦コード、ゲーム数、表示順はスコア編集画面から変更させない。

## 今後の工程

工程⑦で、この対戦結果から最終順位、公式ポイント、賞金、タイトル、PDF、一般公開を確定する。ジャパンオープン以外のダブルエリミネーションへ展開する場合は、対象大会の公式資料を別途確認して設定化する。
