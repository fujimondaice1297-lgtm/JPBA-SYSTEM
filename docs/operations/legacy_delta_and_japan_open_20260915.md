## 操作・確認コマンド

通常の目視確認だけならコマンド実行は不要。開発プロジェクトを開いて以下を実行すると非破壊で再確認できる。

```powershell
Set-Location -LiteralPath 'C:\Users\user\OneDrive\デスクトップ\old jpba\jpba-system'
php artisan jpba:import-japan-open-roster 2026 --json
php artisan jpba:import-official-2026-results --json
php artisan public:parity-audit
php artisan jpba:release-readiness
```

名簿の確定投入はdry-runの件数・メンバー確認後に限り `php artisan jpba:import-japan-open-roster 2026 --force --json`。
大会構成を2026年へ再適用する場合は、必ず `--final-format=round_robin_stepladder` と開催回・大会名・日程・会場を指定し、まず `--force` なしで確認する。デフォルトのDE方式を今年の大会に適用しないこと。

DBスキーマ書き出しコマンド（今回はスキーマ変更なし）：

```powershell
pg_dump -s -h 127.0.0.1 -p 5433 -U postgres -d jpba_main -f "docs\db\SCHEMA.sql"
```
