# 選手アカウント段階導入ガイド（2026-08-27）

## 基本方針

- 認証アカウントは `users.pro_bowler_id` で選手へ結線する。旧プロフィールのログインID・旧パスワードは認証正本にしない。
- パスワードは暗号化保存し、管理者にも表示しない。共通初期パスワードは使わない。
- 未発行選手が「パスワードを忘れた方」を使っても、アカウントを自動作成しない。
- 発行、初期設定メール、利用停止、終了、再開は、管理者の選手編集画面から「アカウント管理」を開いて行う。
- 停止・終了しても選手、大会、ボール、申請、承認履歴は削除しない。

## 本人確認

発行前に、スタッフが次の3点を確認する。

1. 選手氏名とライセンス番号が本人申告と一致する。
2. 選手プロフィールのメールアドレスが本人の受信可能な個人アドレスである。
3. 同じメールが別選手アカウントに使われていない。

メール修正が必要なら、先に選手プロフィールを更新する。電話・対面・既登録連絡先など、協会が通常使う連絡手段で確認し、メール返信だけを本人確認の唯一の根拠にしない。

## 個別発行と初回設定

1. 管理者で選手プロフィール編集を開く。
2. 「新システム 選手アカウント」の「アカウント管理」を開く。
3. メールと会員状態を確認し、「この選手へ発行」を押す。
4. 「初回設定／再設定メールを送信」を押す。
5. 選手がメールのリンクから8文字以上のパスワードを設定する。
6. 管理画面の「パスワード設定」が日時表示へ変わったことを確認する。

発行後に選手プロフィールの氏名・メール・ライセンス番号を修正した場合は、同じ画面の「プロフィール情報を同期」を押す。管理者・編集者アカウントへ誤結線されている場合は同期せず、安全停止する。

コマンドで少人数をまとめて行う場合も、必ず最初にdry-runする。

```powershell
php artisan seed:users-from-bowlers --license=M00001219 --dry-run
php artisan seed:users-from-bowlers --license=M00001219
php artisan seed:users-from-bowlers --license=M00001219 --send-setup-link
```

`--all` と `--send-setup-link` は同時利用できない。全選手へ一斉送信しない。

5. 選手が大会を選び、個数上限内でボールを登録。
6. 速報・大会成績から、公開してよい登録ボール情報だけを閲覧。
7. 差戻し後の再提出と、次大会でのマイボール再利用。

## スタッフ代理入力

- スタッフは選手のパスワードを聞かず、管理者・編集者の自分のアカウントで代理入力する。
- 登録先の選手名、ライセンス番号、`pro_bowler_id` を画面上で再確認する。
- シリアル番号、年度、対象大会、検量証必須条件、登録個数上限を確認する。
- 承認・差戻し理由は選手へ伝え、本人による登録と同じ正本へ保存する。

## 停止・終了・再開

- 一時的にログインを止める場合は「利用停止」とし、理由を必須入力する。
- 退会等で今後利用しない場合は「終了」とし、理由を必須入力する。
- 停止・終了時は既存セッションと未使用のパスワード再設定トークンを破棄する。
- 再開時は「利用中」へ戻し、必要なら再設定メールを送る。
- 状態変更履歴は日時、変更前後、理由、担当者を保持する。
- 本人が公開登録画面から作成した場合も、発行経路とパスワード設定日時を同じ履歴へ保存する。
