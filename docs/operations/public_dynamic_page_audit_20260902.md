# 一般公開の動的ページ監査（2026-09-02）

## 目的

固定URLだけでなく、現行DBの公開データに紐づく選手詳細、大会詳細、速報、全成績、エントリープロ、大会登録ボール、INFORMATION詳細、編集可能な公開ページ、プロテスト速報・結果を公開前監査へ含める。

## 実行方法

```powershell
php artisan public:parity-audit
```

JSONで記録する場合:

```powershell
php artisan public:parity-audit --json
```

動的ページだけを確認する場合:

```powershell
php artisan public:parity-audit --dynamic-only --json
```

## 自動選定

- 公開中の選手プロフィール1件
- 成績またはスコアを持つ公開大会1件
- 上記大会の大会詳細、速報、全成績、エントリープロ、大会登録ボール
- 公開期間内のINFORMATION詳細1件
- 公開中の編集可能ページ1件
- 公開済みプロテスト年度・日別速報各1件

対象データが存在しない種類はスキップする。IDは固定せず、監査時点のDBから公開条件を満たす代表データを選ぶ。

## 合格条件

- HTTPステータスが200～399
- 公開共通ナビとページ固有の主要見出しが存在
- HTML内のローカル画像・PDF参照がすべて解決可能
- コントローラ配信の選手写真・ボール画像も実際にHTTP応答が成功
- 1件でも欠落ラベルまたは欠落アセットがあれば終了コード1

## 今回の修正

- 一般公開のINFORMATION一覧・詳細を会員管理レイアウトから公開サイトレイアウトへ統一した。
- 会員用INFORMATION詳細は従来どおり会員レイアウトを維持した。
- 欠落アセットが存在しても監査結果がOKになっていた判定を修正した。
